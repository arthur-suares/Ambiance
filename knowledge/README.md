# Base de conhecimento Ambiance

Este diretório contém as notas conectadas do projeto. Abra a raiz do repositório `/Users/aluno1/Agro/Ambiance` como um vault no Obsidian.

Comece por [[Início - Ambiance]].

## Regras de manutenção

- Uma nota deve representar um conceito, decisão, fonte ou processo principal.
- Use links internos do Obsidian sempre que citar outro conceito do projeto.
- Registre decisões relevantes como ADR em `05-Decisoes`.
- Diferencie fatos confirmados, hipóteses e pendências.
- Inclua fonte, versão, período e data de acesso ao documentar datasets.
- Atualize [[Histórico de implementação]] depois de mudanças no projeto.
- Não coloque credenciais, dados brutos ou arquivos grandes no vault.

## Convenções de status

- `status: rascunho`: conteúdo em construção.
- `status: validado`: conferido pela equipe ou por teste reproduzível.
- `status: decisão`: escolha arquitetural registrada.
- `status: obsoleto`: preservado apenas para histórico.
