# Desmatamento

O projeto diferencia pelo menos dois conceitos:

- desmatamento territorial observado, fornecido pelo [[MapBiomas]];
- exposição ao desmatamento associada aos fluxos, estimada pelo [[Trase]].

Essas medidas não devem ser somadas ou apresentadas como equivalentes. Veja [[Arquitetura de dados]].
